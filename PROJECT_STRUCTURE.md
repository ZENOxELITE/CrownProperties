# Crown Properties Project Structure

This document describes the files in the Crown Properties React/Vite project.

## Root Files

- `.gitignore` - Lists local, generated, dependency, environment, and editor files that Git should ignore.
- `index.html` - The browser entry document. Defines the root element, favicon, SEO metadata, social sharing metadata, and loads `src/main.tsx`.
- `package.json` - Project metadata, npm scripts, runtime dependencies, and development dependencies.
- `package-lock.json` - Locks the exact npm dependency tree for reproducible installs.
- `README.md` - Short project introduction.
- `eslint.config.js` - ESLint configuration for JavaScript, TypeScript, React, and React Hooks code.
- `postcss.config.js` - PostCSS configuration used by Tailwind CSS and Autoprefixer.
- `tailwind.config.js` - Tailwind content paths plus the shared Crown Properties color and font tokens.
- `vite.config.ts` - Vite configuration, React plugin setup, the `@/` alias for `src/`, and dependency optimization settings.
- `tsconfig.json` - Base TypeScript project configuration and references to the application and Node configurations.
- `tsconfig.app.json` - TypeScript settings for browser/application source files.
- `tsconfig.node.json` - TypeScript settings for Node-based configuration files such as Vite and Tailwind config.
- `PROJECT_STRUCTURE.md` - This file; documents the purpose of each project file and folder.

## Project Customization

- `.bolt/prompt` - Legacy project guidance describing the preferred UI quality, Tailwind usage, Lucide icons, React hooks, and the `@/` import alias.
- `.github/skills/estate-design/SKILL.md` - On-demand project design skill covering fonts, colors, typography, spacing, responsive layouts, imagery, components, and visual verification.

## Public Assets

- `public/favicon.svg` - Browser favicon served from `/favicon.svg`.

## Application Source

- `src/vite-env.d.ts` - Vite type declarations for TypeScript.
- `src/main.tsx` - React entry point. Creates the root, enables Strict Mode, renders `App`, and imports global CSS.
- `src/App.tsx` - Application shell. Sets up React Router routes, navigation, footer, scroll restoration, page background, and the fallback route.
- `src/index.css` - Global CSS, Google Font imports, Tailwind layers, body defaults, focus-visible styles, scrollbar styling, and animation utilities.

## Reusable Components

- `src/components/Nav.tsx` - Sticky site header, logo/agency name, desktop navigation, and mobile navigation menu.
- `src/components/Footer.tsx` - Site footer with agency information, navigation links, contact details, and social links.
- `src/components/Hero.tsx` - Homepage hero area with featured property imagery, headline content, and property highlights.
- `src/components/PropertyCard.tsx` - Reusable property listing card with image, status, price, specifications, details link, and WhatsApp action.
- `src/components/SearchBar.tsx` - Listing search and filter controls.
- `src/components/Gallery.tsx` - Property image gallery with image navigation and full-screen lightbox behavior.
- `src/components/ContactForm.tsx` - Contact form, submission state, fields, and Formspree submission handling.
- `src/components/WhatsAppButton.tsx` - Reusable WhatsApp contact button with size and visual variants.
- `src/components/SEO.tsx` - Route-level document title and meta description handling.
- `src/components/ScrollToTop.tsx` - Scrolls the window to the top when the route changes.

## Data Modules

- `src/data/agency.ts` - Canonical Crown Properties identity, contact details, location, social links, license, statistics, currency, and form endpoint.
- `src/data/properties.ts` - Property type definitions, property listing records, property statuses, and price formatting helpers.
- `src/data/agents.ts` - Agent records, bios, contact details, and agent lookup helpers.
- `src/data/testimonials.ts` - Customer testimonial records used by the homepage.

## Route Pages

- `src/pages/HomePage.tsx` - Homepage composition: hero, featured listings, agency statistics, introduction, testimonials, and calls to action.
- `src/pages/ListingsPage.tsx` - Property listing route with search/filter state, sorting, and property cards.
- `src/pages/PropertyDetailPage.tsx` - Dynamic property detail route for `/property/:slug`, including gallery, specifications, description, agent details, and contact actions.
- `src/pages/AboutPage.tsx` - Agency story, values, team, and company information.
- `src/pages/ServicesPage.tsx` - Services offered by the agency.
- `src/pages/ContactPage.tsx` - Contact form, office details, map embed, and contact methods.

## Runtime And Generated Folders

These folders may exist locally but are not part of the hand-maintained source structure:

- `node_modules/` - Installed npm packages. Generated by `npm install` and ignored by Git.
- `dist/` - Production build output. Generated by `npm run build` and ignored by Git.

## Common Commands

```powershell
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
npm run preview
```

The development server runs the Vite app locally. The production build writes compiled assets to `dist/`.
